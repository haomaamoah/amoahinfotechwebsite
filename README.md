# AMOAH INFOTECH Website

Static business website for AMOAH INFOTECH, an AI-first software engineering company based in Accra, Ghana.

## Files

- `index.html` - Main marketing website.
- `terms.html` - Terms and conditions page.
- `styles.css` - Shared responsive styling.
- `assets/logo.png` - Business logo.
- `assets/terms-and-conditions.pdf` - Downloadable PDF copy of the terms.

## Preview Locally

Run a simple local server from this folder:

```bash
python3 -m http.server 5173
```

Then open:

```text
http://localhost:5173
```

## Deploy

This site is static and can be deployed on Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any standard web host by uploading the folder contents.
